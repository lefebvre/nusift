# Figure data

Committed so `make_figures.py` regenerates the figures without a built CLI or a staged store.
Every file is verbatim CLI output from ENDF/B-VIII.1 (`data/nusift_b8.1.h5`, staged
2026-08-13), with `S="--store data/nusift_b8.1.h5"` and `F="--seed-fission U-235 --yield-kt 20"`:

| File | Command |
| --- | --- |
| `fission-exposure-timeline.csv` | `nusift rank $F $S --times 1m:100y:log:70 --metric exposure --top 8 --format csv` |
| `fission-dominance-windows.csv` | `nusift forecast $F $S --times 1m:100y:log:70 --metric exposure --format csv` |
| `fission-1d-activity.csv` | `nusift rank $F $S --at 1d --metric activity --top 8 --format csv` |
| `fission-1d-exposure.csv` | `nusift rank $F $S --at 1d --metric exposure --top 8 --format csv` |

## Scenario data

The `scenario-*` files feed the capability figures in [../../scenarios.md](../../scenarios.md) and
are regenerated by [`make_data.sh`](make_data.sh) rather than being listed one by one here — the
script IS the list, and a table beside it would be a second place for a command to be recorded
wrongly. Run it after anything that could move the numbers, and commit whatever moved:

```bash
./docs/figures/data/make_data.sh [path/to/nusift] [path/to/store.h5]
```

One of them is an input rather than an output. `scenario-assay.csv` is the same contaminated
component as [`examples/contaminated_component.csv`](../../../examples/contaminated_component.csv),
split across three assay dates with the counting uncertainties attached, so the reconciliation and
uncertainty scenarios have something dated and uncertain to work on.

The script runs every command from the repository root with relative paths, because several of
them echo the input path into their own provenance line. An absolute path there would bake one
checkout's location into committed output and make the regenerate-and-diff check fail everywhere
else.

The air-coefficient figures need no data file: the script parses the NIST table straight out of
`nusift/exposure/air_coefficients.cpp`, so those figures cannot drift from the values the code
actually interpolates.
